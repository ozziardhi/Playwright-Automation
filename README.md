#  Web POS E2E Test Automation Suite

Automated End-to-End (E2E) testing framework built using **Playwright** and **TypeScript** to test critical user flows on the Web POS application.

##  Tech Stack & Tools
* **Test Framework:** Playwright
* **Language:** TypeScript
* **Version Control:** Git & GitHub

##  Test Scenarios Covered
1. **Authentication / Login Feature (`login.spec.ts`)**
   *  Successfully log in using valid credentials
2. **Product Management / Add Product (`add-product.spec.ts`)**
   *  Successfully add a new product (validating name, category, price, and stock input fields).
   *  Form validation checks for required fields.
